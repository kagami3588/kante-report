# NotebookLM 用 指示文

## 使い方
1. NotebookLM で新規ノートブックを作成し、`source_参加者説明資料.md` をソースとして追加する（以前のソースは削除する）。
2. Studio の「スライド資料」のカスタム指示に、下の指示文を貼り付ける。

## 指示文（スライド資料用）
```
研究に参加する中学生・高校生と保護者に向けた、説明スライドを作成してください。
読み手は初めてこの研究を知る人です。見た瞬間に意味が分かることを最優先にします。
構成は、表紙1枚、本編1〜11の11枚、最後に「参加にあたって」1枚の、全13枚です。

【全体のデザイン】
- 全スライドで同じレイアウトにする（左に文字、右に図、または上に文字、下に図）
- フォントはゴシック体1種類のみ。見出しは大きく太く、本文も大きくする
- 文字色は濃いグレー（ほぼ黒）。薄い水色の文字は使わない
- 背景は白かごく淡いクリーム色の無地。装飾の図形や波紋は入れない
- アクセントカラーは青と緑の2色だけ。「自分・自己理解」は青、「他者・親・他者理解」は緑で、全スライドで統一する
- 1枚につき、見出し1つ、本文は最大3行、図は1つ（2枚目だけは表を使ってよい）
- 単語の途中で改行しない。文節の区切りで改行する
- 各スライドの右上に「n / 13」のページ番号を入れる

【図の方針】
- 抽象的な図形や雰囲気だけの装飾は使わない
- 図は、文章の意味を説明するものだけにする
- 図の中には必ず短いラベルを付ける

【文章のルール】
- 中学生が読める言葉づかいにする。難しい言葉には、ふりがなを付ける
- 運命や結果を断定する表現、効果を保証する表現は使わない
- ソースにない情報は追加しない。数字や文言は、ソースのとおりに使う

【スライドごとの内容と図】
表紙: タイトルと、1行の説明。研究テーマ「親と子が宿命を知ることで、キャリアや進路への考え方にどのような影響があるのか」を小さく添える

1. 取り組みの目的: 「自分」と「身近な人」を結ぶ矢印の図。「宿命」の意味（算命学で、生年月日から読み取る生まれ持った性質や傾向。未来や結果が決まっているという意味ではない）を、小さな注釈として下に入れる

2. キャリア教育でも、自己理解・他者理解は大切にされています:
   - 見出しは「どの年代でも、自己理解は大切にされています」
   - 図は、ソースの表を、横に4段階（小学校低学年／小学校高学年／中学校／高等学校）、縦に2段（自己理解＝青、他者理解＝緑）で並べた表にする
   - 各マスには、ソースの表の短い言葉を入れる。自己理解は「好き嫌いを言う → 長所や欠点に気付く → 自分の良さや個性が分かる → 自分を受け入れて伸ばそうとする」。他者理解は「友達と助け合う → 異なる意見も理解しようとする → 他者の良さや感情を尊重する → 他者の価値観や個性を受け入れる」
   - 中学校と高等学校の列を、枠で強調する（今回の参加者の年代）
   - 下に、出典を小さく入れる（国立教育政策研究所「児童生徒の職業観・勤労観を育む教育の推進について」平成14年11月）

3. この取り組みの位置づけ: 左に「キャリア教育の目標（自己理解・他者理解）」、右に「この取り組み（算命学をきっかけにする）」を置き、矢印でつなぐ。下に注意書き「算命学は文部科学省に認定された手法ではなく、効果が公的に保証されているものでもありません。特定の考えを広めることが目的ではありません」を、枠で囲んで目立たせる

4. 自分を知る: 氷山の図。水面の上に「自分が知っている自分」、水面の下に「まだ気づいていない自分」

5. 自分を客観的に捉える: 「自分から見た自分」と「周りから見た自分」を左右に並べ、中央に「ちがうことがある」

6. 親を知る: 「子どもから見た親」の面と、「まだ知らない親の一面」を並べる図

7. 他者を理解する: 親を中心に置き、「子ども（自分）」「友人」「先生」の3方向から矢印を向ける。それぞれの矢印の先に「見え方がちがう」と書く

8. 違いを理解する: 2人のイラストと、それぞれの吹き出し（ちがう考え）。下に「ちがうのは自然なこと」

9. 取り組みの方法: 横一列のタイムライン。「鑑定前アンケート → 鑑定 → 鑑定直後アンケート → 約3か月後アンケート」。子どもと保護者の両方が回答することを明記する

10. 検証したいこと: 左に「確認したい良い変化」（自己理解、他者理解、親子の対話、進路やキャリアの考え方）、右に「確認したい望ましくない影響」（不安、決めつけ）。左右の大きさは同じにし、どちらも確認することを示す

11. 目指す姿: 「違いを知る → 理解しようとする → 自分らしい選択」の3段階の階段

参加にあたって: 4項目（参加は任意／結果は断定しない／回答は研究実施者が責任をもって管理／不安なときは相談できる）を、アイコンと一文で並べる。下に「未成年の方の参加には、保護者の同意をお願いしています」を小さく入れる
```

## 指示文（音声解説・動画用）
```
参加者向けの短い説明として、研究の目的、キャリア教育でも自己理解・他者理解が大切にされていること、進め方（アンケート3回）、参加は任意であることを、3分程度でやさしく説明してください。結果を断定する表現は使わないでください。
```
