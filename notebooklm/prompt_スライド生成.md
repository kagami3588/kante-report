# NotebookLM 用 指示文

## 使い方
1. NotebookLM で新規ノートブックを作成し、`source_参加者説明資料.md` をソースとして追加する。
2. Studio の「スライド資料」（または「レポート」）のカスタム指示に、下の指示文を貼り付ける。

## 指示文（スライド資料用）
```
研究に参加する子どもと保護者に向けた説明スライドを、全10枚で作成してください。
- ソースの「1」から「10」の見出しを、1枚ずつスライドにする
- 各スライドは「見出し」「太字の一言メッセージ」「2〜3行の説明」にする
- 小学校高学年から保護者まで読める、やさしい言葉づかいにする
- 2枚目では、算命学が文部科学省に認定された手法ではなく、効果が公的に保証されていないことを、必ず明記する
- 9枚目では、うまくいかない場合や不安・決めつけといった望ましくない影響も確認することを、必ず明記する
- 運命や結果を断定する表現、効果を保証する表現は使わない
- ソースにない情報は追加しない
- デザインは落ち着いた配色で、余白を多くとる
```

## 指示文（音声解説・動画用）
```
参加者向けの短い説明として、研究の目的、進め方（アンケート3回）、参加は任意であることを、3分程度でやさしく説明してください。結果を断定する表現は使わないでください。
```
