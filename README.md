# KAGAMI 進路・自己理解支援 効果測定システム（Google Apps Script）

鑑定前 → 鑑定直後 → 3ヶ月後 の3時点を同じ対象者IDで結び、
「鑑定 → 自己理解 → 判断軸 → 進路の明確さ → 主体的な行動 → 進路の具体化」を数字で検証します。
（満足度調査ではありません）

## セットアップ
1. script.google.com で新規プロジェクトを作り `Code.gs` と `appsscript.json` を貼り付け
2. `setupKagamiSystem()` を実行（初回のみ）→ 6フォーム＋スプレッドシートが自動生成
3. 既存システムの更新は `updateKagamiSystem()`（回答は消えません。回答があるフォームの質問は差し替えません）
4. `issueSubjectIds()` で対象者ID（KGM-0001…）と事前入力URLを発行

## フォーム（6種）
| 時期 | お子様 | 保護者 | 必須数 |
|---|---|---|---|
| 鑑定前 | E | F | 10 |
| 鑑定直後 | A | B | 13 / 14 |
| 3ヶ月後 | C | D | 16 / 16 |

- 状態の質問9問（自己理解2・判断軸2・進路の明確さ2・自己決定／自己肯定2・不安1）は3時点で同じ意味。全て4段階（中央選択肢なし、数字が大きいほど良い）。
- 3ヶ月後：鑑定活用／主体的行動（4段階）／行動内容（複数選択）／進路状況／鑑定影響／「鑑定がなかった場合」（単一選択＋任意の理由）。

## 変化量
d1=鑑定前→直後、d2=直後→3ヶ月後、d3=鑑定前→3ヶ月後。判定しきい値は設定シート（2問平均±0.5、不安1問±1.0）。

## 分析
全体集計／クロス集計（分析1〜8）／ダッシュボード（検証の流れ・3時点推移・行動・鑑定の影響・「鑑定がなかった場合」・グラフ6種）。
相関 r と鑑定影響率は主観評価・関係の強さであり、因果の証明ではありません。N<30 は参考値。

## 個人情報
フォームでは氏名・メールを聞かず、IDのみ。氏名・メールは任意で「対象者管理」シートにだけ保存します。共有範囲を最小限にしてください。
