# 子ども向け自己理解プログラム｜プロジェクト概要

> 2026-10-22 時点の、口頭での説明をまとめたものです。【案】と書いた箇所は私の提案で、未確定です。

## 名称・キャッチコピー（決定）
- 名称：算命学、親子の対話プログラム
- キャッチ：「わかり合うことは、知ることから始まる。」

## 1. プロジェクトの目的
子どもの自己理解が、将来のキャリアにどのように影響するのかを測定します。自己理解のツールとして、算命学を活用します。

## 2. 教育上の位置づけ
国立教育政策研究所 生徒指導研究センター（平成14年11月）の「職業観・勤労観を育む学習プログラムの枠組み（例）」（4領域8能力の表）に沿います。

表の「職業的（進路）発達課題」の行には、各学校段階で自己理解にかかわる課題が書かれています。
| 段階 | 発達課題（表の記載） |
|---|---|
| 小学校 | 自己及び他者への積極的関心の形成・発展 |
| 中学校 | 肯定的自己理解と自己有用感の獲得 |
| 高等学校 | 自己理解の深化と自己受容 |

この流れ（自己理解 → 自己受容 → 他者理解）を、算命学を通して体験してもらいます。

なお、算命学が公的に認められた手法ではないことは、参加者への説明資料と同様に明記します。

## 3. ゴール
- 家族間のコミュニケーションの量が増える。
- コミュニケーションをしやすい環境をつくる。

## 4. 実施の流れ

### 事前
1. 両親と子どもの生年月日を聞く。
2. 【親】アンケートで、子どもがどんな人間か、客観的な視点でどう思っているかを聞く。
3. 【子ども】コーチングで、両親がどんな人か、普段両親に対してどう思っているかを聞き出す。

### 当日（家族全員が揃う）
4. 子どもの算命学の結果を発表する。
5. 両親が、その結果をどう思うかを発表する。
6. 子どもの自己認識と、親から見た客観的な姿とのズレを確認する。
7. ルール: 親から褒められたら、「ありがとう」と受け取る。自己受容の練習になる。

### 体験してもらうこと
- 両親とのコミュニケーションの楽しさ。
- 自己認識と客観的な自分の差。つまり自己理解の深さが、どこまで明確になるか。

### 将来の拡張
必要であれば、両親版も行い、家族の対話や絆を深める。

## 5. 第1回の範囲
子どもだけにフォーカスした会を開きます。算命学が、客観的な家族のコミュニケーションを生み出すツールとして活用できるかを確かめます。

## 6. 測定したいこと
| 測定対象 | 内容 | 備考 |
|---|---|---|
| 自己理解の深さ | 自己認識と親から見た姿とのズレ（事前の親アンケートと、子どもの自己評価を比較） | 当日のズレ確認も記録 |
| 自己受容 | 褒められたことをどう受け取れたか | 【案】事前・事後のアンケートで測る |
| 他者理解 | 親についての理解（コーチングで聞いた内容との変化） | 【案】同上 |
| コミュニケーション | 家族の会話の量、話しやすさ | 【案】約3か月後にも調査 |
| キャリア | 進路やキャリアについての考え方 | 長期の変化は、第1回だけでは測れない |

## 7. 未確定の事項
1. 対象年齢（前回の説明資料は中学生から高校生）。
2. 参加人数、1回あたりの時間。
3. 測定のタイミング。以前の研究案は「鑑定前・直後・約3か月後」。今回も同じにするか。
4. 子どもが親への本音を話した場合、親に伝える範囲を事前に決めておくか。
5. 当日、親の発言が子どもを傷つけた場合の対応方法。
6. 比較対象（算命学を使わない家族面談など）を置くか。置かなければ、算命学の効果は切り分けられない。
7. キャリアへの影響を測るには長期の追跡が要るため、第1回ではコミュニケーションと自己理解に絞るか。
8. 研究として実施する場合の倫理的な手続き（保護者の同意、結果の取り扱い）。

## 8. 前回の研究案との関係
前回の説明資料は、「親と子が宿命を知ることの影響」を調べる研究でした。今回は、子どもだけに焦点を当て、家族のコミュニケーションを成果に置いています。
- 前回は、説明資料の目的が「自己理解・他者理解」でした。今回はゴールが「家族のコミュニケーション」で、研究テーマと少しずれています。
- 参加者への説明資料は、今回の内容に合わせて直す必要があります（親への事前アンケート、当日の流れ、「褒められたらありがとうと受け取る」ルールの追加）。
