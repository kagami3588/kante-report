# 申込完了メールの設定(Google Apps Script)

フォームの「申し込む」を押すと、お客様のメールアドレスに「鑑定お申し込み完了」のメールを送ります。
控えとして kagami.3588@gmail.com にも BCC で届きます。

1. kagami.3588@gmail.com でログインした状態で https://script.google.com を開き、「新しいプロジェクト」を作る。
2. 初期の `コード.gs` の中身をすべて消し、このフォルダの `Code.gs` を貼り付けて保存する。
3. 右上の「デプロイ」→「新しいデプロイ」→ 種類は「ウェブアプリ」。
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
4. 初回は権限の承認が出る(メール送信の許可)。承認する。
5. 表示された「ウェブアプリのURL」(`https://script.google.com/macros/s/…/exec`)をコピーする。
6. `index.html` の `CONFIG.mailEndpoint` にそのURLを貼る。
7. コードを直したときは、「デプロイを管理」→ 編集 → 新バージョンで更新する(URLは変わらない)。

注意：Gmailの無料アカウントは、1日に送れるメールが約100通までです。
