# 集客導線の設計:宿命早見 → 公式LINE登録 → 日干日支の活かし方 → 個人鑑定

## 1. 目的とゴール

- 宿命早見(無料)を入口にして、公式LINEの友だちを増やす。
- 友だちに「日干日支の活かし方」を届けて、信頼を作る。
- そのうえで、個人鑑定(30,000円)の申し込みへ自然につなげる。

## 2. お客様の流れ(全体像)

```
[集客] Instagram投稿・ストーリー・プロフィール・QR
   │  ※リンクに流入元の印を付ける(例:?src=ig)
   ▼
[1] 宿命早見ページ(無料・登録不要)
   │  生年月日を入れる → 日柱 / 自然のたとえ(イラスト) / 季節 を表示
   ▼
[2] ゲート:「あなたの日干日支の活かし方」は公式LINEで受け取れる
   │  ボタン:「公式LINEで活かし方を受け取る」
   ▼
[3] 公式LINEを友だち追加
   │  あいさつメッセージ(歓迎・使い方)
   ▼
[4] 活かし方メッセージが届く(日干の活かし方+日支の活かし方)
   │  末尾に、個人鑑定のご案内ボタン
   ▼
[5] 追客(任意):数日後に、短い活かし方・お知らせを配信
   ▼
[6] 個人鑑定の申し込みフォーム → 申込コード送信 → 鑑定料・お振込先(いまの仕組み)
```

## 3. 実現方法の2段階

### 段階1:すぐ始められる形(開発が小さい)

- 宿命早見ページに「公式LINEで活かし方を受け取る」ボタンを置く。
- ボタンを押すと、公式LINEが開く。トークには `活かし方 丙午` のような文が入る(日柱ごと)。
- お客様が送信すると、公式LINEの応答メッセージ(キーワード応答)が、その日柱の活かし方を自動で返す。
- 応答メッセージは、日柱ごとに60件登録する(甲子〜癸亥)。登録作業は、GPT用の手順書で効率化できる。
- 弱点:
  - 友だち未登録の人は、追加の流れで、入力済みの文が消える可能性がある(実機で確認が必要)。
  - お客様が送信を押さないと届かない。
  - 利用状況(何人が、どの日柱を見たか)を集計しにくい。

### 段階2:自動化する形(LINEの開発設定が必要)

- 宿命早見を、公式LINEのリッチメニューから、LINEの中で開く(LIFF)。
- ページが、お客様のLINEのユーザーIDと、友だち登録の有無を、自動で判別する。
  - 友だち:活かし方を、ページに表示し、同時に、公式LINEから自動で届ける(Messaging API)。
  - 友だちではない:日柱と季節だけを見せて、友だち追加へ誘導する。
- 利用状況を、スプレッドシートに記録する(日時、日柱、流入元、LINEのユーザーID)。
- 数日後の追客や、日干ごとの出し分けも、自動でできる。
- 必要な作業:LINE Developersの設定(Messaging API、LIFF)、アクセストークンの登録。

おすすめ:**段階1で始めて、反応を見てから段階2へ**。段階1のページ・文章は、段階2でもそのまま使える。

## 4. 必要なコンテンツ(林さんの文章)

宿命早見の「意味」(解説)とは別に、**活かし方**の文章が必要になる。

| 種類 | 数 | 内容の例 |
|---|---|---|
| 日干の活かし方 | 10 | 強み / 仕事で / 人間関係で / 注意点 / 今日からの一歩 |
| 日支(季節)の活かし方 | 12 | 季節の過ごし方 / 動くタイミング / 整えること |
| 日柱の一言(任意) | 60 | 日干×日支の組み合わせならではの一言 |

- スプレッドシートに、新しいシート「活かし方」を作る。
- 列の案:区分(日干/日支/日柱)、キー(丙、午、丙午)、強み、仕事で、人間関係で、注意点、今日からの一歩。
- 初稿は、私が叩き台を作ることもできる。ただし、鑑定の内容に関わるため、林さんの確認と修正が必須。
- 断定的な表現(「必ず〜になる」など)は避け、「〜しやすい」「〜すると活きる」の表現にする。

## 5. 宿命早見ページの変更点

- 日柱・自然のたとえ・季節は、これまでどおり、登録なしで見られる。
- 「日干の意味」「日支の意味」「日柱の解説」の長文は、公式LINE登録後に見せる(ゲート)。
- ページ下に、強い誘導ボタンを置く:
  - 「公式LINEで、あなたの日干日支の活かし方を受け取る」
- 流入元の記録:リンクの `?src=ig`(Instagram)、`?src=qr`、`?src=ad` などを、LINEの文に含める。

## 6. 公式LINE側の設定

- あいさつメッセージ:歓迎の言葉と、「宿命早見で調べると、活かし方が届く」案内。
- リッチメニュー:「宿命早見」「個人鑑定の申し込み」「お問い合わせ」。
- 応答メッセージ:活かし方(日柱60件)と、申込コード(P00〜P10の11件)。
- 友だち追加経路:LINE管理画面の機能で、流入元ごとの追加数を計測する。
- 追客(ステップ配信):3日後・7日後に、短い活かし方と鑑定のご案内。通数の上限に注意。

## 7. 計測する数字(集客ツールとしての成果)

| 指標 | 見方 |
|---|---|
| 早見の利用数 | 宿命早見が、何回使われたか(段階2で自動記録) |
| 友だち追加数・追加率 | 利用者のうち、公式LINEを追加した割合 |
| 活かし方の受信数 | キーワード応答が、何件動いたか |
| 鑑定の申込数・申込率 | 友だちのうち、鑑定を申し込んだ割合 |
| 流入元別の成果 | Instagramなど、どこからの人が、よく登録・申込するか |

## 8. 個人情報・表現の注意

- 生年月日は、お客様の端末の中で計算するだけにして、サーバーには送らない。記録するのは、日柱と流入元だけにする(段階2のLINEユーザーIDは、LINE側の情報として扱う)。
- 「個人情報の取り扱い」に、宿命早見と活かし方の配信について、一文を足す。
- 活かし方の配信を、お客様がいつでも止められること(ブロック・配信停止)を、あいさつメッセージに書く。
- 占いの表現は、断定や不安をあおる言い方を避ける。

## 9. 進め方(提案)

1. 活かし方の文章の形式を決める(列、文字数、トーン)。
2. 林さんが、日干10個分を、先に書く(見本)。
3. 見本をもとに、私が日支12個分・日柱60個分の叩き台を作り、林さんが直す。
4. 宿命早見ページに、ゲートとLINE誘導ボタンを追加する。
5. 応答メッセージ60件の登録(GPT用の手順書を、私が作る)。
6. 実機で、通しの動作確認(友だち未登録の場合も)。
7. 反応を見て、段階2(LIFFと自動配信)へ。

## 10. 決めること

1. 活かし方は、日干と日支だけにするか、日柱(60)の一言まで作るか。
2. 活かし方の文章は、林さんが書くか、叩き台を私が作るか。
3. まず、段階1で始めてよいか。
4. 集客の入口は、Instagramが中心か。ほかにもあるか。
5. 追客のメッセージ(ステップ配信)は、最初から入れるか。
